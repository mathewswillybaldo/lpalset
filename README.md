# Alset Marketing

Arquivos do site, versão 4, exportados em 12/11/2026.

## GitHub
1. Extraia o ZIP no computador.
2. Crie um repositório no GitHub.
3. Envie o conteúdo da pasta extraída para a raiz do repositório. O index.html deve ficar na raiz, ao lado de support.js e da pasta vendor.
4. Mantenha todos esses arquivos juntos: os scripts são necessários para as interações da página.

## Vercel
Importe o repositório como site estático (preset Other). Não é necessário instalar dependências nem executar um build. A raiz do projeto contém o index.html.

## Arquivos
- index.html: conteúdo, estilos e lógica da página.
- support.js: runtime usado pela página.
- vendor/: bibliotecas React e ReactDOM já incluídas.

As fontes do Google dependem de internet. Links para WhatsApp e outros serviços externos continuam apontando aos destinos definidos no site.

Não há banco de dados ou servidor neste pacote. Os arquivos foram exportados do projeto original; não se trata de um projeto Next.js/Vite.
